# 귀띔 개인정보 처리방침

시행일: [게시하는 날짜]

귀띔은 명지전문대학 학생에게 맞는 학교 공고와 교외 공모전 공고(출처 사이트 이름과 원문 링크 표시)를 골라 보여 주는 앱이며, AI:ON 2026 대회 출품작입니다. 이 문서는 귀띔 팀이 어떤 정보를 받고, 어디에 두고, 언제 지우는지 적은 것입니다.

## 1. 받는 정보

| 정보 | 언제 | 왜 |
|---|---|---|
| Google 계정 식별자(Firebase UID), 이메일 주소, 이름, 프로필 사진 주소 | Google 계정으로 로그인할 때 | 로그인 상태 유지, 내 정보와 다른 사람 정보 구분 |
| 학교, 학과, 학년, 재학 상태, 관심 분야, 희망 직무 | 내 정보에 직접 입력할 때 (모두 선택, 비워 둘 수 있음) | 맞춤 공고 추천, 공고 지원 조건과 비교 |
| 저장한 공고 목록 | 공고를 저장할 때 | 저장함·달력에 보여 주기 |
| 크레딧 잔액, 사용 내역(받거나 쓴 시각, 수량, 어떤 공고에 썼는지) | 크레딧을 받거나 쓸 때 | 상세 분석 횟수 관리, 내역 화면에 보여 주기 |
| AI 상세 분석 동의 기록(동의 문구 버전, 동의한 시각) | AI 상세 분석에 처음 동의할 때 | 동의 여부 확인, 문구가 바뀌면 다시 묻기 |
| AI 상세 분석 리포트 저장본 | 상세 분석을 마쳤을 때 | 같은 공고를 다시 볼 때 보여 주기 |
| 서버 접속 기록(IP 주소, 접속 시각, 요청 주소) | 앱이 서버에 요청할 때 자동으로 | 오류 확인 |

공고 본문은 학교·출처 사이트가 공개한 공지 원문이며 사용자 정보가 아닙니다. 상세 분석 입력으로만 쓰도록 서버에만 두고 앱은 읽지 못합니다.

받지 않는 정보: 성적, 학번, 연락처, 주민등록번호, 소득, 학생증, 자유 입력 글(자기소개·포트폴리오 등)

상세 분석을 요청할 때 고르는 항목(해 본 것, 가능한 시기, 갈 수 있는 지역)은 서버에 저장하지 않습니다. 분석하는 동안만 서버 메모리에 있다가 버립니다. '다음에도 이대로'를 켜면 기기에만 둡니다.

외부 공고 찾기에서 '직접 적기'(선택, 50자 이내)에 쓴 문장은 찾는 데만 씁니다. 서버에 저장하지 않고, 요청이 끝나면 버리며, 사용 내역에도 남기지 않습니다. 이름·연락처 같은 개인정보는 적지 마십시오.

기기에만 두는 정보: 화면 모드(라이트·다크), 오늘의 귀띔을 본 날짜, '졸업생 진로 추천'에 답한 내용, 저장한 공고의 신청 진행 상태(준비 중·신청함·이번엔 안 함). 서버로 보내지 않으며 앱을 지우면 함께 지워집니다.

## 2. 쓰는 곳

- 맞춤 공고 추천, 지원 조건 비교, AI 상세 분석·외부 공고 찾기, 크레딧 관리에만 씁니다.
- 광고, 판매에 쓰지 않습니다.
- 다른 회사·기관에 제공하지 않습니다. 서비스 운영을 위해 처리를 맡기는 곳은 3장(DeepSeek, AI 기능에 동의하고 상세 분석·외부 공고 찾기를 요청할 때만)과 4장(Google)에 적었습니다.
- 다른 사용자는 내 프로필과 저장 목록을 볼 수 없습니다.

## 3. 국외 이전(처리 위탁)

AI 상세 분석과 외부 공고 찾기는 외부 AI 서비스를 씁니다. 상세 분석을 요청하면 공고 본문과 고른 조건을 외부 AI로 보냅니다. AI 상세 분석 동의(한 번)에 외부 공고 찾기도 포함되며, 동의하지 않으면 아래 내용은 일어나지 않습니다.

AI에는 이름·이메일·계정 식별자·학번 같은 직접 식별 정보를 보내지 않습니다. 추천에 필요한 학교·학과·학년 등은 귀띔이 정한 목록의 값(코드)으로만 보내며, 학생과 연결할 수 있는 식별자는 함께 보내지 않습니다.

| 항목 | 내용 |
|---|---|
| 받는 곳 | DeepSeek (중화인민공화국). 계약 법인: Hangzhou DeepSeek Artificial Intelligence Co., Ltd. |
| 보내는 항목 | 학교, 학과, 학년, 재학 상태, 관심 분야, 희망 직무, 요청할 때 고른 항목(해 본 것, 가능한 시기, 갈 수 있는 지역)을 목록의 값(코드)으로, 그리고 분석할 공고 내용(요약·조건과 공고 본문. 본문은 앞 4,000자까지). 외부 공고 찾기에서는 고른 항목과 직접 적은 문장(선택) |
| 보내지 않는 것 | 이름, 이메일, 계정 식별자(Firebase UID), 학번 등 직접 식별 정보. 요청과 학생을 연결하는 식별자. 내 기기의 IP 주소(AI에는 귀띔 서버가 대신 보냄) |
| 주의 | 학교·학과·학년 같은 항목도 다른 정보와 합치면 사람을 좁힐 수 있는 정보입니다. 그래서 필요한 칸만 목록의 값으로 보냅니다. 외부 공고 찾기에서 직접 적은 문장은 적은 그대로 보내지므로 이름·연락처 같은 개인정보는 적지 마십시오. |
| 목적 | 그 공고에 대한 맞춤 분석(리포트) 만들기, 외부 공고 찾기 |
| 시점·방법 | 상세 분석이나 외부 공고 찾기를 요청할 때마다, 암호화된 인터넷 연결(HTTPS)로 보냄 |
| DeepSeek 쪽 보관 | 정해진 보관 기간이 없고, 목적을 달성하면 파기한다고 밝히고 있습니다. 보낸 내용은 DeepSeek 모델 학습에 쓰일 수 있습니다. 귀띔은 DeepSeek이 제공하는 학습 거부 설정을 켜 두지만, 이 설정이 API 요청에 적용되는지는 DeepSeek이 밝히지 않았습니다. (2026-11-22 DeepSeek 개인정보처리방침 기준) |
| 거부 방법 | 동의하지 않거나, 내 정보에서 'AI 상세 분석 동의 철회'를 누릅니다. 거부해도 기본 공고 분석은 무료로 계속 쓸 수 있습니다. |

## 5. 보관 기간과 지우는 방법

| 대상 | 기간 |
|---|---|
| 프로필, 저장한 공고 목록 | 탈퇴할 때까지 |
| 요청할 때 고른 항목 | 요청이 끝나면 버림 (서버 메모리만) |
| 외부 공고 찾기에 직접 적은 문장 | 요청이 끝나면 버림 (서버 메모리만, 사용 내역·로그에도 남기지 않음) |
| AI 상세 분석 리포트 저장본 | 공고 마감일 + 30일(마감 시각이 없으면 그 날 0시 기준). 마감일을 알 수 없으면 만든 뒤 60일 |
| 공고 본문(서버 전용, 상세 분석 입력용 공개 공지 원문) | 공고를 게시하는 동안. 공고를 내리면 함께 지움 |
| 크레딧 사용 내역 | 최근 90일 |
| AI 상세 분석 동의 기록 | 탈퇴할 때까지 |
| DeepSeek 쪽 입력·출력 | DeepSeek 기준에 따름 (3장) |

- 탈퇴하면 프로필, 저장한 공고 목록, 크레딧 잔액·내역, 동의 기록, 리포트 저장본, 로그인 계정을 바로 지웁니다. 공고 자체는 모두가 보는 정보라 남습니다.
- AI 상세 분석 동의를 철회하면 저장된 리포트도 지웁니다.
- 리포트 저장본·크레딧 사용 내역은 하루 한 번 정리하므로, 기간이 지난 뒤 최대 하루 늦게 지워질 수 있습니다.
- 서버 로그에 AI에 보낸 내용(프롬프트)과 받은 답(응답) 원문을 남기지 않습니다. 요청 시각, 공고 번호, 사용한 AI 연결 방식, 걸린 시간, 토큰 수, 비용, 성공 여부, 공고 본문을 썼는지 여부(있음·없음·잘림)만 남깁니다.
- 서버 접속 기록은 Google Cloud 기본 설정에 따라 약 30일 뒤 자동으로 지워집니다.
- 대회가 끝나 운영을 마치면 남은 사용자 정보를 지우고 이 문서에 적습니다.

탈퇴하는 법: 앱 홈 오른쪽 위 **내 정보** → **탈퇴하기** → Google 계정 한 번 더 확인

앱을 이미 지웠다면 아래 문의처로 로그인했던 Google 계정 이메일을 알려 주시면 지워 드립니다.
