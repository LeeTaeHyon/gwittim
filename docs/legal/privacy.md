# 귀띔 개인정보 처리방침 (체험판)

시행일: 2026년 11월 5일

귀띔은 명지전문대학 학생에게 맞는 학교 공고를 골라 보여 주는 앱입니다. 지금 배포하는 앱은 AI:ON 2026 대회 심사 기간에 써 보기 위한 체험판입니다. 이 문서는 귀띔 팀이 어떤 정보를 받고, 어디에 두고, 언제 지우는지 적은 것입니다.

## 1. 받는 정보

| 정보 | 언제 | 왜 |
|---|---|---|
| Google 계정 식별자(Firebase UID), 이메일 주소, 이름, 프로필 사진 주소 | Google 계정으로 로그인할 때 | 로그인 상태 유지, 내 정보와 다른 사람 정보 구분 |
| 학교, 학과, 학년, 재학 상태, 관심 분야, 희망 직무 | 내 정보에 직접 입력할 때 (모두 선택, 비워 둘 수 있음) | 맞춤 공고 추천, 공고 지원 조건과 비교 |
| 저장한 공고 목록 | 공고를 저장할 때 | 저장함·달력에 보여 주기 |
| 서버 접속 기록(IP 주소, 접속 시각, 요청 주소) | 앱이 서버에 요청할 때 자동으로 | 오류 확인 |

받지 않는 정보: 성적, 학번, 연락처, 주민등록번호, 소득, 학생증

기기에만 두는 정보: 화면 모드(라이트·다크), 오늘의 귀띔을 본 날짜, '졸업생 진로 추천'에 답한 내용. 서버로 보내지 않으며 앱을 지우면 함께 지워집니다.

## 2. 쓰는 곳

- 맞춤 공고 추천과 지원 조건 비교에만 씁니다.
- 광고, 판매, 다른 회사·기관 제공에 쓰지 않습니다.
- 다른 사용자는 내 프로필과 저장 목록을 볼 수 없습니다.

## 3. 두는 곳

귀띔 팀은 별도 서버를 두지 않고 Google 서비스를 씁니다.

| 서비스 | 맡는 일 | 위치 |
|---|---|---|
| Firebase Authentication (Google) | Google 로그인, 계정 식별자·이메일·이름 보관 | Google 데이터센터 |
| Cloud Firestore (Google) | 프로필, 저장한 공고 보관 | 서울 리전 |
| Cloud Run (Google) | 앱 서버, 접속 기록 | 서울 리전 |

## 4. 보관 기간과 지우는 방법

- 탈퇴할 때까지 보관합니다.
- 탈퇴하면 프로필, 저장한 공고 목록, 로그인 계정을 바로 지웁니다. 공고 자체는 모두가 보는 정보라 남습니다.
- 서버 접속 기록은 Google Cloud 기본 설정에 따라 약 30일 뒤 자동으로 지워집니다.
- 체험판 운영을 마치면 남은 사용자 정보를 지우고 이 문서에 적습니다.

탈퇴하는 법: 앱 홈 오른쪽 위 **내 정보** → **탈퇴하기** → Google 계정 한 번 더 확인

앱을 이미 지웠다면 아래 문의처로 로그인했던 Google 계정 이메일을 알려 주시면 지워 드립니다.
