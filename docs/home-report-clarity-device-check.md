## 1. 홈: 이번 주 마감 카드

- [ ] 1-1. 구역 제목 오른쪽은 '앞으로 7일'. '전체 N건 >'이 없음
- [ ] 1-2. 공고 줄마다 오른쪽 끝에 회색 `>` 화살표
- [ ] 1-3. 7일 안 후보가 5건 넘으면 카드 맨 아래 가운데 'N건 더 보기 ∨'
- [ ] 1-4. N = 접힌 카드에 안 보이는 7일 안 공고 수(아래 '새 공고'에 있는 것 포함)
- [ ] 1-5. 줄을 누르면 리포트가 열림. 'N건 더 보기'를 누르면 달력으로 가지 않고 그 자리에서 펼침
- [ ] 1-6. 두 곳을 헷갈리지 않고 누를 수 있음(손가락으로 각 5회, 오동작 없음)

## 2. 홈: 펼치기·접기

- [ ] 2-1. 펼치면 같은 카드에 7일 안 공고 전부, 마감 가까운 순
- [ ] 2-2. 펼친 줄 중 새 공고에는 '새 공고' 표시, 마감이 바뀐 저장 공고에는 변경 문구
- [ ] 2-3. 펼친 동안 아래 '새 공고' 구역에서 같은 공고 줄이 사라짐(다 사라지면 구역 제목까지)
- [ ] 2-4. 펼친 동안 맨 아래 같은 공고의 마감 변경 카드가 사라짐
- [ ] 2-5. 귀띔 말풍선 건수가 펼치기 전후 같음
- [ ] 2-6. '접기 ∧'를 누르면 원래 구성으로 돌아옴
- [ ] 2-7. 높이 변화가 부드러움(끊김·깜빡임 없음)
- [ ] 2-8. 설정 > 접근성 > 애니메이션 삭제(줄이기)에서 움직임 없이 바로 바뀜
- [ ] 2-9. 다른 탭에 갔다 와도 펼친 상태 유지
- [ ] 2-10. 당겨서 새로 고침 후에도 펼친 상태 유지
- [ ] 2-11. 앱을 완전히 닫고 다시 켜면 접힌 상태

## 3. 리포트: 결론 카드

- [ ] 3-1. 제목·출처 바로 아래, '내 지원' 카드보다 위에 테두리 카드
- [ ] 3-2. 줄 순서 조건 → 마감 → 추천, 줄마다 아이콘·이름표·값
- [ ] 3-3. 확인 필요 공고: '확인 필요 N개'(주황), N이 아래 체크리스트 안내 문장 개수와 같음
- [ ] 3-4. 조건 충족 공고: '조건 충족'(남색/하늘색)
- [ ] 3-5. 조건 미충족 공고(있으면): '조건 미충족 · 학년' 등(빨강)
- [ ] 3-6. 7일 안 마감은 빨강, 그보다 멀면 기본 글자색
- [ ] 3-7. 오늘 마감 공고(있으면): 시각이 있으면 '오늘 17:00 마감', 없으면 '오늘 마감'
- [ ] 3-8. 마감일 없는 공고: 원문 설명(예: '예산 소진 시까지') 또는 '마감일 미상'
- [ ] 3-9. 모집 상태 미확인 공고: 조건·추천 줄도 보임
- [ ] 3-10. 모집 마감·삭제 공고(있으면): 마감 줄 하나에 '마감' 또는 '삭제된 공고'
- [ ] 3-11. 저장 목록·관련 공지에서 연 공고(추천 정보 없음): 조건 줄 없이 마감(+추천 없음)
- [ ] 3-12. 저장한 공고: 결론 카드 아래 '내 지원' 카드가 그대로 보임

## 7. 실데이터로 재현이 어려운 경우(로컬 서버)

- 대상: 칩 여러 개가 한 줄에 붙는 경우, 상태 원이 오른쪽으로 가면서 좁아진 제목 칸의 두 줄 배치
- 실제 서버 데이터에는 해당 공고가 없을 수 있어 로컬 서버에서 공고 사본을 바꿔 확인. 원본 `data/local/notices.json`과 실제 서버 데이터는 건드리지 않음

### 7-0. 준비

- [ ] 공고 사본: `data/local/notices.json`을 복사하고, 이번 주 마감 공고 하나를 골라 아래 두 값을 바꿈
  - `published.date` → 오늘('새 공고' 표시)
  - `application_deadline.date` → 오늘부터 7일 안(이번 주 마감 줄)
  - 추천 이유가 길게 나오도록 관심 분야·직무·전공이 모두 걸리는 공고(컴퓨터공학과 프로필이면 'Build with Qwen' 등)
- [ ] 로컬 서버: 사본을 올려 8767 포트로 실행(에뮬레이터 점검과 같은 방식, `docs/handoff.md` 로컬 서버 절). 프로필 넣기
  ```
  curl -X PUT -H "Authorization: Bearer dev-token" -H "Content-Type: application/json" \
    http://127.0.0.1:8767/v1/profile \
    -d '{"university_id":"mjc","major_id":"mjc.computer_engineering","grade":2,"enrollment_status":"enrolled","interest_ids":["software","ai_data","design"],"target_role_ids":["software_developer"],"updated_at":"2026-11-25T03:00:00Z"}'
  ```
- [ ] 폰을 PC 서버에 연결: `adb -s <기기> reverse tcp:8767 tcp:8767`
- [ ] PR 빌드를 로컬 서버용으로 다시 빌드해 덮어 설치
  - `--dart-define=GWITTIM_API_BASE=http://127.0.0.1:8767/ --dart-define=GWITTIM_DEV_TOKEN=dev-token`, 버전 옵션은 기존 PR 빌드와 같게
  - `adb install -r --user 0 <apk>`. 같은 서명이면 폰 데이터 유지. 저장 동작이 실제 서버 계정에 남지 않음
- [ ] 좁은 폭(약 360dp)·최대 글자
  ```
  adb -s <기기> shell wm density 640
  adb -s <기기> shell settings put system font_scale 2.0
  ```
