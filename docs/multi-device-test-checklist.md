## 2. 맞춤 공고 선별

- [ ] A(명지): 명지 학교 공지 + 교외 공고, 소프트웨어·AI 관련 공고가 위쪽
- [ ] B(숭의): 숭의 공지는 보이고 명지 공지는 안 보임(D-043), 디자인·미디어 관련 공고가 위쪽
- [ ] C(학교 없음): 교외 공고만, "학교를 고르면…" 안내 표시
- [ ] D(목록에 없는 학교): 학교 공지 없이 교외 공고만
- [ ] 같은 공고 1건(예: 명지 장학 공지)을 네 계정에서 열어 지원 조건 판정이 계정마다 다름 (예: A 충족, D 졸업 조건으로 불충족 또는 확인 필요)
- [ ] 홈 '오늘의 귀띔'·'곧 마감되는 공고'가 계정마다 다름
  - 알림은 앱 안 표시만 본다. 푸시는 P0 제외, 기기 알림은 #179 병합 전

## 3. 계정별 데이터 격리

- [ ] 저장(북마크): A에서 2건, B에서 다른 1건 저장 → 각 저장함에 자기 것만
- [ ] 카톡 넘긴 공고: A·B에서 서로 다른 글을 '붙여넣기'로 넘김 → 각자 '카톡에서 넘긴 공고'에 자기 것만
- [ ] 크레딧: 게스트 3, 구글 5(첫 가입). 한 계정에서 써도 다른 계정 잔액 변화 없음
- [ ] (선택) 상세 분석: 한 계정에서만 1건 실행 (동의 화면은 본인이 직접 선택, 크레딧 1개·1원 안팎) → 다른 계정에서 같은 공고에 '분석 결과 보기' 없음
- [ ] Firestore: `users/{uid}/saved`, `shared_notices`, 크레딧 문서가 각자 uid 아래에만 (읽기만)
