# 맞춤 에이전트 브레인스토밍 안건 (30분)

- 대상: 팀장, 팀원
- 근거: [decisions.md](decisions.md) D-039
- 목적: 학생 입장에서 답이 갈리는 4가지만 정함. 기술 세부(API, 저장, 상한)는 따로 명세로 검토

## 이미 정한 것 (공유만, 5분)

- 기본 공고 분석: 지금처럼 무료
- 상세 분석: 공고에서 버튼을 누르면 그 학생 기준 리포트 제공. 외부 AI(Claude Haiku) 사용, 1건 약 3.3원
- 리포트 칸: 요약 / 지원 자격 / 필요한 역량 / 이 학생에게 맞는 점 / 지원 전 할 일
- 외부 공고 찾기: 서버가 모아 둔 교외 공고에서 맞는 것을 골라 이유와 함께 제공
- 크레딧: 가입 시 5개, 매일 1개 충전, 최대 5개 보유. 상세 분석 1개, 외부 공고 찾기 2개
- 하지 않는 것: 합격 가능성 예측, 지원서 도우미, 면접 준비
- 외부 AI에 보내는 정보: 학교·학과·학년·재학 상태·관심사·직무만

## 안건 1. 크레딧 양 (5분)

- 매일 1개, 최대 5개가 인색한지 넉넉한지
- 한 주에 상세 분석을 몇 번쯤 쓸 것 같은지
- 외부 공고 찾기 2개가 적당한지
- 참고: 숫자는 비용으로만 계산한 값. 2배로 늘려도 사용자 1,000명 기준 월 몇만 원 수준

## 안건 2. 상세 분석 화면 (10분)

- 버튼 위치: 공고 상세 화면 어디에, 어떤 이름으로
- 리포트 5개 칸 중 실제로 읽을 칸, 빼도 되는 칸
- 칸 순서: 무엇을 맨 위에 둘지
- 받은 리포트를 다시 보는 곳(공고 안, 별도 목록)
- 기다리는 10초 안팎 동안 보여 줄 것

## 안건 3. 다음 기능 우선순위 (5분)

- 후보 A: 주간 맞춤 요약 (이번 주 새 공고 중 나에게 맞는 것)
- 후보 B: 저장한 공고 비교 (2~3개 중 무엇이 더 맞는지)
- 후보 C: 공고에 질문하기 ("휴학생도 되나요?")
- 기준: 일반 AI(ChatGPT 등)에 물어도 되는 기능은 하지 않음. 우리 앱에만 있는 자료(검증된 공고, 마감, 조건 판정, 프로필)를 쓰는 기능만
- 빠진 아이디어가 있는지

## 안건 4. 크레딧이 없을 때 (5분)

- 안내 문구와 위치: 버튼을 누르기 전에 보일지, 누른 뒤에 알릴지
- 다음 충전 시각을 보여 줄지
- 광고 보고 충전(1회 +1개)은 실제 서비스 단계로 미룸. 받아들일 만한지 의견만
