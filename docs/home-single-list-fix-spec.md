## 2. 고칠 것

### 2.1 말풍선: 이름과 건수가 갈리지 않게 (결함)

- 지금: `home_screen.dart`의 `_Nudge`에서 `'${keepTogether(p.name)} '` 뒤에 건수가 이어집니다. 사이가 일반 공백이라 줄이 넘치면 '새 공고' / '1건'으로 갈릴 수 있습니다(홈 명세 §5.1 위반).
- 바꿈: 이름과 건수 사이를 줄바꿈 없는 공백(`\u00A0`)으로 잇습니다. 덩어리 사이(' · ')는 그대로 줄이 바뀔 수 있습니다.
- 줄이 바뀔 때 가운뎃점이 다음 줄 맨 앞에 오지 않게 합니다(가운뎃점은 앞 덩어리 뒤에 붙임: 앞 덩어리 + `\u00A0·` + 일반 공백 + 다음 덩어리).
- 테스트: 세 건수가 모두 있고 폭 360·글자 1.3배(그리고 2배)일 때 말풍선 글의 줄마다 '이름 N건'이 통째로 들어 있다. 글자 넘침 오류가 없다.

### 2.2 줄 배치: 조건 상태 원은 제목 옆에만, 메타 줄은 전체 폭

- 지금: `_HomeLine`에서 상태 원이 글 묶음(표시 + 제목 + 메타) 전체의 오른쪽을 차지합니다. 글자 1.3배에서 메타가 '… 공모전·경진대회 ·' / '관심·직무·전공'으로 넘어가 줄이 4줄이 됩니다(컴공 프로필 5줄 중 3줄).
- 바꿈(마감 줄·아이콘 줄 공통): 글 묶음을 위에서부터
  1. 제목 위 표시(있을 때, 전체 폭)
  2. 제목 줄: 제목(남는 폭) + 간격 8 + 상태 원(위 맞춤)
  3. 메타 줄(전체 폭)
  로 둡니다. 상태 원은 제목 첫 줄과 위를 맞춥니다. 표시가 있어도 원은 표시 옆이 아니라 제목 옆입니다.
- 메타가 그래도 넘치면 지금처럼 라벨 단위로 줄이 바뀝니다. 이때 가운뎃점이 줄 끝에 홀로 남지 않게 라벨 앞 가운뎃점을 그 라벨에 붙입니다(`' ·\u00A0라벨'`: 줄바꿈은 가운뎃점 앞에서).
- 그 밖의 값(글자 크기·색·간격·날짜 블록·분류 아이콘)은 그대로입니다.
- 확인: 에뮬레이터 컴공 프로필 글자 1.3배에서 'D-6 · 공모전·경진대회 · 관심·직무·전공'이 한 줄에 들어간다.

### 2.3 최신 모드 줄에는 조건 상태 원을 두지 않음

- 지금: 프로필이 없는 사용자(최신 모드)에게도 줄마다 '확인 필요' 원이 붙습니다. 비교할 프로필이 없어 전부 같은 값입니다.
- 바꿈: `list.personalized`가 아니면 홈 줄에 상태 원을 그리지 않습니다. 맞춤 추천일 때는 지금 그대로입니다(추천 정보가 없는 저장 공고만 원 없음).
- 테스트: 최신 모드 홈에 `EligibilityDot`이 없다. 맞춤 홈에는 있다.

### 2.4 마감 변경 카드: 홈 줄에 나온 공고면 그리지 않음

- 지금: 마감이 바뀐 저장 공고가 마감 줄에 있을 때만 맨 아래 변경 카드를 뺍니다. 그 공고가 새 공고·마감이 먼 맞춤 공고 줄에 나오면 줄과 카드에 두 번 나옵니다.
- 바꿈:
  - `buildHomeSections`의 `changed`는 홈 줄(마감·새 공고·마감이 먼 맞춤 공고) 어디에도 나오지 않은 공고만 담습니다.
  - 아이콘 줄(새 공고·마감이 먼 맞춤 공고)도 저장한 뒤 마감이 바뀐 공고면 메타 마지막을 추천 이유 대신 `deadlineChangeText`(`sub` 600)로 둡니다(마감 줄과 같은 규칙).
