# 앱 화면 다듬기 명세

- 작성일: 2026-10-25 (Asia/Seoul)
- 근거: 2026-10-25 팀장 검토("네비바 구성도 그렇고 너무 dev 느낌"), [UI 스타일 가이드](ui-style.md), 결정 기록 D-006·D-009·D-010·D-011
- 상태: 2026-10-25 U1~U10 구현(PR #38, 2026-10-25 main 병합). 결정 질문(§3)은 추천안으로 정했습니다(D-012).
- 이번 산출물: 이 문서. 각 작업은 한 PR·한 산출물로 따로 요청합니다.

## 1. 목표와 범위

앱이 시제품이나 개발 화면처럼 보이는 곳을 없애고, 귀띔다운 단정한 화면으로 다듬습니다.

**범위**
- Flutter 앱(`apps/mobile`)의 화면 모양, 배치, 문구 표시 방식, 움직임.

**범위 밖**
- 서버·계약·사전은 바꾸지 않습니다.
- 새 기능을 더하지 않습니다(SPEC P0 그대로).
- 새 패키지를 들이지 않습니다. 아이콘과 그림은 로고처럼 `Path`로 직접 그립니다.

**모든 작업에 공통으로 지킬 것**
- 스타일 가이드([ui-style.md](ui-style.md))를 따르고, 새 규칙이 생기면 가이드도 같은 PR에서 고칩니다.
- 데이터 정확성 표시는 숨기지 않습니다(SPEC §1, D-009). 모양만 바꿉니다.
  - '확인 필요'와 '마감일 없음'
  - 마감일 없는 공고를 '다가오는 마감'에서 뺀 건수 안내
  - 24시간이 지난 정보 안내(D-006)
  - 브리핑과 리포트의 '합격 가능성을 뜻하지 않아요'(D-009)
- 라이트·다크 스크린샷, 애니메이션 줄이기 설정, 큰 글자 설정을 확인합니다(가이드 §8 점검 목록).

## 5. 작업별 명세

### U1. 하단 탭

- **범위:** `lib/ui/components.dart`(`GwTabBar`), `lib/main.dart`(`HomeShell`), 새 아이콘 파일 `lib/ui/icons.dart`(제안).
- **아이콘:**
  - Material 기본 아이콘 대신 탭 아이콘을 직접 그립니다.
  - 선 굵기 2, 끝 둥글게, 24 칸 안에 그리고, 선 모양(고르지 않음)과 채운 모양(고름)을 한 벌씩 둡니다.
  - '오늘(홈)' 아이콘에는 말풍선 모양을 넣어 로고와 이어지게 합니다.
- **이름과 구성:** Q1·Q2 답대로 바꿉니다. 프로필을 탭에서 빼면 홈 머리 오른쪽에 프로필 아이콘 버튼을 둡니다.
- **고른 탭 표시:**
  - 지금의 진한 색·굵은 글자에 더해, 아이콘 아래 지름 4의 라임 점을 둡니다(라임은 면으로만 쓰는 규칙 안).
  - 점은 탭이 바뀌면 옮겨 가며 커졌다 작아집니다(320ms).
- **유지할 것:**
  - 누름 표시(72×52, 반지름 12)와 진동, 좌우 화면 전환
  - 탭을 오가도 화면 상태가 유지되는 것
  - 화면 읽기 '○○, 선택됨, 버튼'
- **완료 기준:**
  - 라이트·다크 스크린샷
  - `tab_bar_test.dart` 갱신(아이콘이 그린 아이콘인지, 이름, 고른 탭 점 위치)
  - 기존 화면 테스트 통과
  - 스타일 가이드 §7 갱신

### U2. 로딩 자리표시

- **범위:** 위 5곳의 `CircularProgressIndicator`, `lib/ui/components.dart`에 공통 위젯(제안 이름 `GwSkeleton`, `GwLoadingLogo`).
- **목록·리포트(Q4 A):**
  - 그 화면의 카드 모양을 닮은 회색 면(`neutral`)을 보입니다.
  - 면은 1.2초 주기로 밝기만 은은하게 바뀝니다.
- **앱 시작·로그인 대기(Q4 B):** 로고 크기 그대로, 말풍선 안에서 점 세 개가 차례로 깜빡입니다.
- **지킬 것:**
  - 애니메이션 줄이기 설정이면 깜빡이지 않습니다.
  - 화면 읽기에는 '불러오는 중'으로 읽힙니다.
- **완료 기준:**
  - 5곳 모두 교체
  - 회전 원이 코드에 남지 않음(`grep CircularProgressIndicator` 0건)
  - 라이트·다크 스크린샷

### U3. 오류·빈 화면, 새로고침 표시

- **범위:** `lib/ui/common.dart`(`MessageView`), `saved_screen.dart` 빈 상태, `RefreshIndicator` 2곳.
- **오류 화면:**
  - 구름 아이콘 대신 작은 말풍선 그림(로고 말풍선을 `neutral` 색으로, 글자 없음)을 씁니다.
  - 그 아래에 한 줄 제목과 한 줄 설명(해요체)을 둡니다.
  - 버튼은 앱 버튼으로 바꿉니다. '다시 시도'는 `SoftButton` 모양입니다.
- **빈 저장 탭:**
  - 같은 그림을 쓰고 '아직 저장한 공고가 없어요'를 보입니다.
  - '공고 둘러보기' 버튼으로 홈(또는 Q1 B의 '공고' 탭)으로 갑니다.
- **새로고침 표시:** 색을 토큰(`cta` 원, `card` 바탕)으로 바꿉니다.
- **지킬 것:** 상세 오류·스택은 계속 보이지 않습니다(`errorMessage`).
- **완료 기준:**
  - `FilledButton.tonal`·`cloud_off`가 코드에 남지 않음
  - 오류·빈 화면 위젯 테스트(문구, 버튼 동작)
  - 라이트·다크 스크린샷

### U4. 화면 이동과 상단 바

- **범위:** `home_screen.dart`·`saved_screen.dart`의 `MaterialPageRoute` 3곳, `report_screen.dart`·`briefing_screen.dart`의 `AppBar`.
- **화면 이동:**
  - 공통 경로(제안 이름 `gwRoute`)로 바꿉니다.
  - 공고 리포트는 오른쪽에서 48 밀려 들어오며 나타나고(320ms, 탭 전환과 같은 곡선), 뒤로 가면 반대로 갑니다.
  - 하루 첫 브리핑은 아래에서 올라와 흐려진 상태로 나타납니다.
- **상단 바:**
  - 스크롤하기 전에는 지금처럼 비어 있습니다.
  - 내용이 상단 바 밑으로 들어가면 바탕이 `card`로 채워지고 아래 구분선(`line`)이 생깁니다.
  - 리포트는 이때 공고 제목을 한 줄(16/600, 말줄임)로 보입니다.
- **아이콘:** ←·✕를 U10의 아이콘 계열로 맞춥니다.
- **완료 기준:**
  - 이동 방향과 상단 바 변화를 확인하는 위젯 테스트
  - 에뮬레이터에서 뒤로 가기 제스처 확인

### U5. 홈 구역 정리와 카드

- **범위:** `lib/ui/home_screen.dart`.
- **구역 역할 안(Q3):**
  - **오늘의 귀띔:** 숫자 요약만(마감 임박 N개, 맞춤 공고 N개, 마감 바뀐 저장 공고 N개) + '브리핑 보기'. 공고 제목을 다시 쓰지 않습니다.
  - **다가오는 마감:** 2주 안 마감 공고 날짜 목록. 지금 모양 유지.
  - **나에게 맞는 공고:** 추천 순서와 추천 이유는 그대로 둡니다. 다가오는 마감과 겹치는 공고도 빼지 않습니다(보여 주는 이유가 다름). 반복은 아래 '카드'에서 칩을 줄여 덜 보이게 합니다.
  - Q1이 B면 이 목록은 '공고' 탭으로 옮기고, 홈에는 상위 3개와 '전체 보기'만 둡니다.
- **카드:**
  - 칩은 가장 중요한 하나만 둡니다. 7일 이내 마감이면 D-day, 아니면 '확인 필요'처럼 상태가 있으면 그것을 둡니다.
  - 분류는 제목 위 작은 글자(13, `muted`)로 내립니다.
  - '조건 충족'은 칩 대신 추천 이유 줄 앞의 작은 체크 표시로 바꿉니다.
- **지킬 것:**
  - '확인 필요'는 목록에서 회색입니다(D-009).
  - 마감일 없는 공고를 뺀 건수 안내는 남깁니다. 모양은 U6에서 바꿉니다.
- **완료 기준:**
  - `app_test.dart`의 홈 검사 갱신(구역 순서, 반복 표시)
  - 서로 다른 프로필 3개(SPEC §3 검증 지점)에서 홈 스크린샷

### U6. 메타 줄과 안내 문구

- **범위:** 홈·리포트·저장 화면의 가운뎃점 줄, 회색 안내 문구.
- **메타 줄:**
  - 가운뎃점으로 네 개 넘게 잇지 않습니다.
  - 날짜·시각처럼 중요한 것은 앞에 굵게, 나머지는 줄을 바꾸거나 작은 아이콘(달력·시계)과 함께 둡니다.
  - 예: '10월 30일(금) 17:00 마감' / '행사'
- **안내 문구:**
  - 홈 끝의 '합격 가능성' 문구는 뺍니다. D-009는 브리핑과 리포트에만 요구합니다.
  - 브리핑·리포트의 문구는 남기되, 추천 이유 구역 제목 옆 (i) 버튼을 누르면 펼쳐지는 안내로 옮길지 팀장이 화면을 보고 정합니다. 기본안은 지금 위치에 두고 글자만 12.5 `muted`로 낮추는 것입니다.
  - '학교 공지를 바탕으로 정리했어요'는 요약 말풍선 오른쪽 아래 작은 꼬리표로 줄입니다.
  - '마감일이 정해지지 않은 공고 N개(선착순 등)는 넣지 않았어요'는 남기고, 구역 끝 작은 안내 줄로 바꿉니다. 누르면 그 공고들을 보여 주는 것은 선택 사항입니다(새 화면이 필요하면 따로 요청).
- **완료 기준:**
