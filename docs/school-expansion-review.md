# 다른 학교 게시판 조사 (학교 팩 첫 확인)

- 조사일: 2026-11-21
- 근거: [D-043](decisions.md) 확장 방향(교외 공고 기본층 + 학교 팩)
- 대상: AI:ON 연합 대학 2곳 — 배화여자대학교, 숭의여자대학교
- 방법
  - `GwittimBot/0.1 (non-commercial student project)`, 요청 간 3초, 로그인 없음
  - 학교당 robots.txt, 메인, 게시판 목록 1페이지, 상세 1건만 읽음. 받은 HTML은 저장소에 넣지 않음
  - 이용약관 페이지 유무는 메인·게시판 하단 링크로만 확인
- 상태: 조사만. 수집 코드·계약 변경 없음. 학교 이용 허락 요청 전

## 결론

- 두 학교 모두 공지 게시판은 로그인 없이 열리고, robots.txt가 게시판 경로를 막지 않음
- 세 학교(명지·배화·숭의) 게시판 시스템이 **모두 다름** → 학교마다 어댑터 1개는 필요
  - 공통 수집 파이프라인(`backend/collectors/common`)은 그대로 재사용. 학교별 몫은 목록·상세 파서(명지 `backend/collectors/mjc_www` 기준 테스트 빼고 약 500줄)
- 숭의는 바로 붙일 수 있는 수준, 배화는 본문이 첨부(PDF·HWP)에 있는 공고가 있어 첨부 처리가 관건
- 첨부 경로와 robots (2026-11-21 다시 확인)
  - 배화: 첨부는 `/cmmn/download.do?idx=`로 받음. robots가 막는 `/down/`과 다른 경로라 **받을 수 있음**
  - 숭의: 첨부 파일은 `notice.do?mode=download`로 받을 수 있음. 단, **본문에 넣은 이미지(포스터)는 `/_attach/…/editor-image/`라 robots가 막음** → 포스터에만 있는 내용은 읽지 않고 원문 링크로 안내
- 숭의 게시판 URL 형식(`notice.do?mode=list&article.offset=`)은 숙명여대 등 다른 대학에서도 보임 → 같은 업체 CMS면 **어댑터 하나로 여러 학교**를 덮을 가능성 (미확인)

## 주의할 점

- 배화 목록 JSON에 게시자 접속 IP(`IP_ADDR`) 필드가 들어 있음 → 파서에서 버리고 저장·로그에 남기지 않음
- 숭의 robots는 AI 봇을 포함해 특정 봇을 전체 차단함(11/21 낮 11개, 같은 날 밤 다시 볼 때 16개로 늘어남)(일반 크롤러·감시 도구도 섞여 있어 'AI 수집 거부'로 단정할 수는 없음). 우리 봇 이름은 해당하지 않지만, 맞춤 에이전트가 공고 본문을 외부 LLM(Anthropic)에 보내므로 이용 허락 요청 때 LLM 분석 여부를 밝힐 것
- 두 학교 모두 약관이 없어 명지와 같은 상태(수집·재표시 허락 미확인). 기술적으로 열린 것과 이용 허락은 별개 (source-review §2와 같은 판단)
- 수집 주기는 명지와 같은 상한을 둔다: 학교마다 최소 3시간 간격([source-review.md](source-review.md) §2), 요청 사이 3초 이상
- 표본이 학교당 상세 1건(첨부 경로 확인용으로 학교당 1건 더 봄). 배화의 "본문은 첨부" 비율, 숭의의 포스터 이미지 비율은 재지 않음

## 표본 확대·같은 CMS 확인 (2026-11-21 밤)

- 표본: 학교당 목록 3페이지 + 상세 15건(요청 배화 23·숭의 19건, 429·403 없음, 원문 저장 안 함)
  - 배화: 상세 15건 중 14건이 본문 텍스트 100자 미만, 15건 모두 본문 이미지(포스터). '본문은 첨부'보다 **'본문은 포스터 이미지'**가 맞음. 첨부는 8건(대부분 hwp, 확인한 1건은 신청서 양식). 이미지 경로 `/uploads/BOARD/`는 robots 허용
  - 숭의: 상세 15건 중 10건이 본문 텍스트 100자 이상. robots가 막는 본문 이미지에만 내용이 있는 공고는 1건
  - 학생 기회 공고 비율: 배화 공지 40%, 배화 장학/대출 87%, 숭의 공지 44%(애매는 따로 셈)
- 같은 CMS 후보: 확실 4곳(숙명 대표 사이트·아주·이화·영남), 가능성 3곳(성균관·고려·연세 일부). 숭의 고유 주소 문자열은 검색으로 확인 못 해 어댑터 그대로 재사용은 미확인
  - 숙명·아주·영남·연세는 ClaudeBot·GPTBot 등 AI 봇을 전체 차단, 숙명·영남·연세는 `/_attach/`(본문 이미지)도 차단
- 결론 보강: 배화를 붙이려면 포스터 읽기(OCR·이미지 입력)가 관건. 숭의는 본문 텍스트로 충분
