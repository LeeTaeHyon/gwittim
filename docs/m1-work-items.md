## 5. 운영 원칙

- 작업마다 허용 파일 범위 밖은 수정하지 않습니다. 공통 계약 변경이 필요하면 AGENTS §3 절차를 따릅니다.
- 라이브러리 추가(예: Flutter 패키지, 웹 프레임워크, HTML 파서)는 해당 작업 PR에서 용도·대안·라이선스를 적고 승인을 받습니다.
- 클라우드 리소스 생성·배포는 이 표로 승인되지 않습니다. 팀장의 별도 요청이 있을 때만 진행합니다.
- 체크 항목은 실제 실행 결과가 있을 때만 완료로 기록합니다. 샘플 기반 완료와 실제 출처 연결 완료를 구분합니다.
