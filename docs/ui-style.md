# 귀띔 앱 스타일 가이드

마지막 갱신: 2026-10-30

앱 화면과 위젯을 만들거나 고칠 때 따르는 규칙입니다. 근거는 결정 기록 [D-009](decisions.md)(UI v2), D-010(다크 테마·저장·프로필·로그인), D-011(로고)과 2026-10-25 팀장 검토입니다.

- 값은 코드에서 가져왔습니다: 색은 `apps/mobile/lib/ui/theme.dart`, 공통 위젯은 `lib/ui/components.dart`, 로고는 `lib/ui/logo.dart`, 시작 인트로는 `lib/ui/intro.dart`.
- 2026-10-25 기준으로 일부는 아직 열린 PR에 있습니다. 로고·인트로는 #31~#33, 하단 탭은 #34, 가운데 선택 팝업은 #35이고, 병합되면 코드와 이 문서가 일치합니다.
- 화면 다듬기([ui-polish-spec.md](ui-polish-spec.md) U1~U10, D-012)로 탭 구성·아이콘·로딩·오류·위 막대·화면 이동 규칙을 더했습니다(`feat/ui-polish`).
- 규칙을 바꾸면 코드와 이 문서를 같은 PR에서 고칩니다. 큰 방향이 바뀌면 `docs/decisions.md`에도 남깁니다.

## 0. 원칙

- 비서 앱답게 단정하게 만듭니다. 화려한 장식, 굵고 둥근 투박한 모양, 튀는 움직임은 쓰지 않습니다.
- Flutter 기본 모양을 그대로 두지 않습니다. 기본 아래 창, 알약 표시가 있는 Material 탭 막대, 원형 리플 같은 것은 이 문서의 모양으로 바꿉니다.
- 색은 토큰 이름(`context.gw.○○`)으로만 씁니다. 화면 코드에 `Color(0x…)`를 직접 쓰지 않습니다.
  - 예외 두 가지: Google 로그인 버튼(브랜딩 가이드 색), 테마 밖에서 그리는 시작 인트로(`GwColors.light` 사용).
- 라임은 면으로만 씁니다. 라이트·다크 모두 라임을 글자색으로 쓰지 않습니다.
- 새 화면은 라이트와 다크를 둘 다 확인합니다.

### 문구

해요체(~요)는 쓰지 않습니다(D-022). 자리에 따라 둘 중 하나로 씁니다.

| 자리 | 말투 | 예 |
|---|---|---|
| 배지·칩, 카드 한 줄, 구역 제목, 빈 화면·오류 제목, 버튼 | 명사형 | '조건 충족', '확인 필요', 'D-3', '오늘 마감', '마감 3일 연장', '추천 이유', '불러오기 실패', '확인' |
| 짧은 결과 알림(`SnackBar`) | 합쇼체, '~되었습니다' | '공고가 저장되었습니다.', '저장이 취소되었습니다.' |
| 오류 설명, 안내·주의 문장 | 합쇼체 | '로그인에 실패했습니다. 잠시 후 다시 시도해 주세요.', '합격 가능성과는 관계없습니다.' |

- 사용자에게 부탁할 때는 '~해 주세요'를 씁니다.
- '~해 드려요', '~해 드릴게요'처럼 서비스를 내세우는 말은 쓰지 않습니다. 예외는 로그인 소개 한 줄입니다.
- '~되었습니다' 같은 피동형은 짧은 결과 알림에만 씁니다. 다른 문장은 능동형('비교했습니다')이나 명사형으로 씁니다.
- 조건 결과는 '충족 / 미충족 / 확인 필요'로 통일합니다. '불충족', '맞아요'는 쓰지 않습니다.
- 말투를 바꿔도 뜻은 그대로 둡니다. 예를 들어 '합격 가능성을 뜻하지 않음'을 '보장하지 않음'으로 바꾸면 합격 가능성을 어느 정도는 알려 주는 것처럼 읽힙니다.
- **줄바꿈:** 두 줄 이상이 될 수 있는 문장(안내·설명·캡션·알림)과 공고 제목은 `keepAll()`(`lib/ui/format.dart`)을 거쳐 보입니다. Flutter는 한글 음절 사이에서도 줄을 바꿔 '주세\n요.'처럼 어절이 갈라지기 때문입니다.
  - 띄어쓰기에서만 줄이 바뀝니다. 영문·숫자·기호끼리(URL 등)는 원래 규칙을 따르고, 한 어절이 한 줄보다 길면 그 안에서 바뀝니다.
  - 끝 문장이 14자 이하이면 통째로, 아니면 끝 두 어절을 묶어 마지막 줄에 한 어절만 남지 않게 합니다.
  - `TipBubble`·`MessageView`의 설명, 체크리스트 메모에는 이미 들어 있습니다. 새 문장 `Text`나 공고 제목을 보이는 곳을 만들면 직접 감쌉니다.
  - 한 줄로 자르는 곳(상단 바 제목, `maxLines: 1`)과 짧은 배지·라벨에는 쓰지 않습니다.
  - 테스트에서 이런 문구를 찾을 때는 `test/finders.dart`의 `findText`·`findTextContaining`을 씁니다.

### 크기

- 칩 `Pill`은 높이 26입니다.
- 고르는 칩은 높이 44에 테두리 1.5이고, 보조 버튼 `SoftButton`은 높이 44입니다.
- 큰 버튼은 높이 56이고, 세그먼트 한 칸은 높이 44입니다.
- 누를 수 있는 곳은 48×48 이상으로 합니다. 막대 안의 칸처럼 보이는 표시는 작아도 누르는 영역은 칸 전체로 둡니다.

### 그 밖

- **그림자:** 쓰지 않습니다. 면은 바탕과 카드 색 차이로 나눕니다.
- **간격:**
  - 화면 좌우 여백은 16~24, 카드 안 여백은 18~22(기본 20)입니다.
  - 구역 사이는 28~44이고, 제목과 내용 사이는 8~12입니다.
- **아이콘:**
  - 하단 탭·내 정보·저장(책갈피) 아이콘은 직접 그린 `GwIcon`(`lib/ui/icons.dart`)입니다. 24 칸, 선 굵기 2, 끝과 꺾임은 둥글게 그리고, 선 모양(고르지 않음)과 채운 모양(고름)이 한 벌씩 있습니다. '오늘' 아이콘은 로고와 같은 말풍선입니다.
  - 그 밖의 아이콘은 Material `_rounded` 계열만 씁니다(`_outlined`·기본 계열을 섞지 않음). 새 아이콘을 더하면 `grep "Icons\." lib`로 계열을 확인합니다.
- **그림:** 오류·빈 화면에는 글자 없는 로고 말풍선(`GwBubbleMark`, 높이 44, `line` 색)을 둡니다. 라이트의 `neutral`은 화면 바탕과 같아서 `line`으로 칠합니다.
- **로고:** `GwLogo`만 씁니다.
  - 배지 `GwBadge`는 높이 28, 작은 배지는 22입니다.
  - 로그인 화면은 56, 시작 인트로는 93.75(폭 150)입니다.
  - 원본은 `docs/brand/logo.svg`이고, 테스트가 코드와 원본의 도형이 같은지 확인합니다.

## 4. 움직임

- **곡선:** 나타나거나 바뀔 때는 `Curves.easeOutCubic`을 씁니다. 끝에서 튀는 곡선은 쓰지 않습니다. 예외는 시작 인트로의 말풍선 등장과 로그인 소개 장면의 말풍선·체크 표시 등장(아주 살짝 넘침)입니다.
- **애니메이션 줄이기:** 모든 움직임은 기기 설정(`MediaQuery.disableAnimations`)이 켜져 있으면 시간을 0으로 합니다.
- **사라질 때:** 너무 빨리 사라지지 않게 합니다. 손을 뗀 뒤 남는 반응은 0.3초 이상 보이게 합니다.

| 움직임 | 시간 | 내용 |
|---|---|---|
| 누름 표시 나타남 / 사라짐 | 90ms / 450ms | 누르는 동안 칠하고, 손을 떼면 천천히 사라짐 |
| 누름 줄어듦 | 누를 때 120ms, 돌아올 때 360ms | 0.92배 |
| 색·아이콘 바뀜 | 320ms | 하단 탭 색, 선↔채움 아이콘 |
| 탭 화면 전환 | 320ms | 나가는 화면은 바로 감추고, 들어오는 화면만 좌우 48에서 밀려 들어옴(흐려짐 없음). 오른쪽 탭으로 가면 오른쪽에서 들어옴. 화면 두 장을 겹쳐 흐리게 하면 GPU 그리기가 프레임당 30~50ms까지 늘어 끊김(2026-11-03 S25 Ultra 측정) |
| 팝업 열림 | 260ms | 0.94배에서 커지며 흐려진 상태로 나타남 |
| 목록 높이 변화 | 220ms | 검색으로 목록 길이가 바뀔 때(`AnimatedSize`) |

  - 테마가 떠 있는 알약 모양과 `toast` 색, 15/600 글자를 줍니다.

  - 상세 오류와 스택은 보이지 않고 `errorMessage`의 문구만 보입니다.
  - 이미 목록이 있으면 목록은 두고 짧게 알립니다(`showRefreshFailed`).
