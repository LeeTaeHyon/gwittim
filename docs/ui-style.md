# 귀띔 앱 스타일 가이드

마지막 갱신: 2026-10-25

앱 화면과 위젯을 만들거나 고칠 때 따르는 규칙입니다. 근거는 결정 기록 [D-009](decisions.md)(UI v2), D-010(다크 테마·저장·프로필·로그인), D-011(로고)과 2026-10-25 팀장 검토입니다.

- 값은 코드에서 가져왔습니다: 색은 `apps/mobile/lib/ui/theme.dart`, 공통 위젯은 `lib/ui/components.dart`, 로고는 `lib/ui/logo.dart`, 시작 인트로는 `lib/ui/intro.dart`.
- 2026-10-25 기준으로 일부는 아직 열린 PR에 있습니다. 로고·인트로는 #31~#33, 하단 탭은 #34, 가운데 선택 팝업은 #35이고, 병합되면 코드와 이 문서가 일치합니다.
- 화면 다듬기([ui-polish-spec.md](ui-polish-spec.md) U1~U10, D-012)로 탭 구성·아이콘·로딩·오류·위 막대·화면 이동 규칙을 더했습니다(`feat/ui-polish`).
- 규칙을 바꾸면 코드와 이 문서를 같은 PR에서 고칩니다. 큰 방향이 바뀌면 `docs/decisions.md`에도 남깁니다.

## 0. 원칙

- 비서 앱답게 단정하게 만듭니다. 화려한 장식, 굵고 둥근 투박한 모양, 튀는 움직임은 쓰지 않습니다.
- Flutter 기본 모양을 그대로 두지 않습니다. 기본 아래 창, 알약 표시가 있는 Material 탭 막대, 원형 리플 같은 것은 이 문서의 모양으로 바꿉니다.
- 색은 토큰 이름(`context.gw.○○`)으로만 씁니다. 화면 코드에 `Color(0x…)`를 직접 쓰지 않습니다.
  - 예외 두 가지: Google 로그인 버튼(브랜딩 가이드 색), 테마 밖에서 그리는 시작 인트로(`GwColors.light` 사용).
- 라임은 면으로만 씁니다. 라이트·다크 모두 라임을 글자색으로 쓰지 않습니다.
- 새 화면은 라이트와 다크를 둘 다 확인합니다.

### 반지름

| 무엇 | 반지름 |
|---|---|
| 화면 아래쪽 큰 판(저장·프로필 목록 판) | 위쪽 28 |

- 말풍선의 꼬리(작은 반지름)는 왼쪽 아래입니다. 귀띔 로고의 꼬리와 같은 방향입니다.

### 크기

- 칩 `Pill`은 높이 26입니다.
- 고르는 칩은 높이 44에 테두리 1.5이고, 보조 버튼 `SoftButton`은 높이 44입니다.
- 큰 버튼은 높이 56이고, 세그먼트 한 칸은 높이 44입니다.
- 누를 수 있는 곳은 48×48 이상으로 합니다. 막대 안의 칸처럼 보이는 표시는 작아도 누르는 영역은 칸 전체로 둡니다.

### 그 밖

- **그림자:** 쓰지 않습니다. 면은 바탕과 카드 색 차이로 나눕니다.
- **간격:**
  - 화면 좌우 여백은 16~24, 카드 안 여백은 18~22(기본 20)입니다.
  - 구역 사이는 28~44이고, 제목과 내용 사이는 8~12입니다.
- **아이콘:**
  - 하단 탭·내 정보·저장(책갈피) 아이콘은 직접 그린 `GwIcon`(`lib/ui/icons.dart`)입니다. 24 칸, 선 굵기 2, 끝과 꺾임은 둥글게 그리고, 선 모양(고르지 않음)과 채운 모양(고름)이 한 벌씩 있습니다. '오늘' 아이콘은 로고와 같은 말풍선입니다.
  - 그 밖의 아이콘은 Material `_rounded` 계열만 씁니다(`_outlined`·기본 계열을 섞지 않음). 새 아이콘을 더하면 `grep "Icons\." lib`로 계열을 확인합니다.
- **그림:** 오류·빈 화면에는 글자 없는 로고 말풍선(`GwBubbleMark`, 높이 44, `line` 색)을 둡니다. 라이트의 `neutral`은 화면 바탕과 같아서 `line`으로 칠합니다.
- **로고:** `GwLogo`만 씁니다.
  - 배지 `GwBadge`는 높이 28, 작은 배지는 22입니다.
  - 로그인 화면은 56, 시작 인트로는 93.75(폭 150)입니다.
  - 원본은 `docs/brand/logo.svg`이고, 테스트가 코드와 원본의 도형이 같은지 확인합니다.

## 4. 움직임

- **곡선:** 나타나거나 바뀔 때는 `Curves.easeOutCubic`을 씁니다. 끝에서 튀는 곡선은 쓰지 않습니다. 예외는 시작 인트로의 말풍선 등장(아주 살짝 넘침)입니다.
- **애니메이션 줄이기:** 모든 움직임은 기기 설정(`MediaQuery.disableAnimations`)이 켜져 있으면 시간을 0으로 합니다.
- **사라질 때:** 너무 빨리 사라지지 않게 합니다. 손을 뗀 뒤 남는 반응은 0.3초 이상 보이게 합니다.

| 움직임 | 시간 | 내용 |
|---|---|---|
| 누름 표시 나타남 / 사라짐 | 90ms / 450ms | 누르는 동안 칠하고, 손을 떼면 천천히 사라짐 |
| 누름 줄어듦 | 누를 때 120ms, 돌아올 때 360ms | 0.92배 |
| 색·아이콘 바뀜 | 320ms | 하단 탭 색, 선↔채움 아이콘 |
| 탭 화면 전환 | 320ms | 좌우 48 이동과 흐려짐. 나가는 화면은 앞 40% 동안 사라지고, 들어오는 화면은 20% 지점부터 나타남. 오른쪽 탭으로 가면 오른쪽에서 들어옴 |
| 팝업 열림 | 260ms | 0.94배에서 커지며 흐려진 상태로 나타남 |
| 목록 높이 변화 | 220ms | 검색으로 목록 길이가 바뀔 때(`AnimatedSize`) |
| 형광펜 긋기 | 700ms(+지연) | 왼쪽에서 오른쪽으로 |
| 브리핑 항목 떠오름 | 600ms(+지연) | 아래 16에서 올라오며 나타남 |
| 시작 인트로 | 1.25초 | 네이비 바탕에 말풍선이 꼬리 끝에서 등장 → '귀띔' 한 획씩 → 흐려지며 앱으로 |
| 화면 이동 | 320ms | `gwRoute`(테마 기본 전환도 같음). 공고 리포트처럼 옆 화면은 오른쪽 48에서, 하루 첫 브리핑은 아래 48에서 들어오며 흐려진 상태로 나타남. 아래 화면은 움직이지 않음 |

| 단계 화면 전환 | 320ms | 프로필 고치기에서 다음 단계는 오른쪽, 앞 단계는 왼쪽에서 살짝 밀려 들어옴 |
| 로딩 자리표시 | 1.2초 주기 | 회색 면의 밝기만 100%↔55%로 은은하게. 로고 점 세 개는 1.2초에 한 바퀴 |

## 5. 누름 반응

- **하단 탭:**
  - 누르는 동안 아이콘과 이름 둘레(72×52, 반지름 12)를 `tabActive` 10%로 칠하고 0.92배로 줄입니다.
  - 다른 탭을 고르면 짧은 진동(`HapticFeedback.selectionClick`)이 있습니다.
- **카드·목록 줄·버튼:**
  - `InkWell` 물결을 쓰고, 모양의 반지름에 맞춰 자릅니다(`borderRadius` 또는 `customBorder`).
  - 원형으로 번지는 리플(`InkResponse` 무경계)은 쓰지 않습니다.
- **고른 상태:**
  - 목록에서 하나를 고르면: 칩 색 면(`chip`) + 진한 글자(`onChip`, 700) + 오른쪽 원 체크(`point` 면에 `pointTick` 체크)
  - 세그먼트: `cta` 면 + `onCta` 글자
  - 여러 개 고르는 칩: `cta` 면 + 체크 아이콘
  - 하단 탭: 면 없이 색과 채운 아이콘만

## 6. 팝업과 알림

- **하나 고르기**(학교·학과 등)는 화면 가운데 팝업으로 엽니다(`showGeneralDialog` + `Dialog`).
  - 모양: 반지름 24, 바탕 `card`, 최대 폭 420·높이 560, 뒤 바탕은 검정 45%
  - 제목은 '○○ 선택'(20/700)이고 오른쪽 위에 닫기(✕) 버튼이 있습니다.
  - 바깥을 누르거나 닫기를 누르면 바꾸지 않고 닫힙니다. 항목을 누르면 바로 닫힙니다.
  - 항목이 8개를 넘으면 위에 '○○ 이름으로 찾기' 칸을 둡니다. 찾는 항목이 없으면 '찾는 ○○가 없어요'를 보입니다.
  - 고른 항목이 목록 아래로 가려져 있으면 열 때 보이는 곳까지 내려 둡니다.
- **아래에서 올라오는 창(bottom sheet)은 쓰지 않습니다**(2026-10-25 팀장 결정).
- **짧은 결과 알림**은 `SnackBar`로 합니다.
  - 테마가 떠 있는 알약 모양과 `toast` 색, 15/600 글자를 줍니다.
  - 문구는 '저장했어요.', '프로필을 저장했어요.'처럼 해요체 한 줄입니다.
- **오류:**
  - 상세 오류와 스택은 보이지 않고 `errorMessage`의 문구만 보입니다.
  - 이미 목록이 있으면 목록은 두고 짧게 알립니다(`showRefreshFailed`).
  - 빈 화면에는 `MessageView.error`를 둡니다: 말풍선 그림, 한 줄 제목('불러오지 못했어요'), 한 줄 설명(`errorMessage`), `SoftButton` 모양의 '다시 시도'.
- **빈 목록:** `MessageView`에 제목·설명과 다음 행동 버튼을 둡니다(예: 저장함 '아직 저장한 공고가 없어요' + '공고 둘러보기').
- **불러오는 중:** 회전 원(`CircularProgressIndicator`)은 쓰지 않습니다.
  - 목록·리포트·내 정보는 그 화면 모양을 닮은 스켈레톤(`lib/ui/skeleton.dart`)을 씁니다. 화면 바탕 위에서는 `card` 면 위에 `neutral` 면을 올립니다.
  - 앱 시작·로그인 대기는 `GwLoadingLogo`(로고 크기 그대로, 말풍선 안 점 세 개)를 씁니다.
  - 화면 읽기에는 '불러오는 중'으로 읽히고, 애니메이션 줄이기 설정이면 멈춰 있습니다.
- **당겨서 새로고침:** 테마가 `cta` 원과 `card` 바탕을 줍니다.
- **확인을 묻는 팝업**(예: 지우기 전에 묻기)은 아직 없습니다. 만들게 되면 선택 팝업과 같은 모양을 쓰고 이 문서에 더합니다.

## 7. 화면 구조

- **하단 탭:** 바닥에 붙은 `GwTabBar`를 씁니다. 탭은 '오늘·공고·저장함' 셋이고, 내 정보는 홈 머리 오른쪽 아이콘 버튼으로 엽니다(D-012).
  - 높이 64에 시스템 아래 여백을 더하고, 위쪽에 구분선이 있습니다.
  - 고른 탭은 채운 아이콘 + `tabActive` + 700, 나머지는 선 아이콘 + `onTab` + 500입니다.
  - 고른 탭 아이콘 아래(아이콘과 이름 사이)에 지름 4의 라임 점이 있습니다.
  - 떠 있는 캡슐 모양은 쓰지 않습니다(2026-10-25 팀장 결정, D-010 보완).
- **탭 화면:** 앱 바 없이 `ScreenHeader`(22/700)로 시작합니다. 상태 표시줄 아이콘 색은 `statusBarStyle`로 맞춥니다.
- **탭 상태:** 탭을 오가도 각 화면의 스크롤과 입력 상태는 유지합니다.
- **들어가는 화면**(공고 리포트, 하루 첫 브리핑, 내 정보, 프로필 고치기)은 `gwRoute`로 열고 위에 `GwTopBar`를 둡니다.
  - 왼쪽 뒤로(←, '뒤로') 또는 오른쪽 닫기(✕, 예: '브리핑 닫기') 하나만 둡니다.
  - 스크롤 전에는 비어 있고, 내용이 밑으로 들어가면 `card` 바탕과 구분선이 생깁니다. 리포트는 이때 공고 제목을 16/600 한 줄로 보입니다.
- **아래 고정 버튼:** 버튼 위 24는 바탕색으로 흐려지는 그라데이션을 두고, 목록 끝에는 버튼 높이만큼 비워 글이 잘려 보이지 않게 합니다(브리핑).
- **메타 줄:** 가운뎃점으로 네 개 넘게 잇지 않습니다. 남은 날·시각처럼 중요한 것을 앞에 굵게(7일 이내는 `urgent`), 분류는 뒤에 흐리게 둡니다. 예: 'D-5 · 17:00 마감 · 행사'.
- **목록 카드 칩:** 하나만 둡니다. 7일 안 마감이면 D-day, 아니면 조건 상태('확인 필요' 회색). 분류는 제목 위 13 `muted` 글자, 조건 충족은 추천 이유 앞 작은 체크입니다.
- **큰 글자 설정:** 하단 탭처럼 높이가 정해진 막대는 글자를 1.3배까지만 키웁니다(`MediaQuery.withClampedTextScaling`). 다른 곳은 글자가 커지면 칸도 같이 늘어나게 둡니다.
