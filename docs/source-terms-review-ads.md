# 교외 출처 약관 재검토: 광고 충전을 넣을 경우 (D-038 보완)

- 확인일: 2026-11-22 (각 사이트 이용약관 원문 페이지를 다시 읽음)
- 계기: 크레딧 광고 충전(D-039, "실제 서비스 단계로 미룸")을 넣으면 D-038의 수집 근거가 유지되는지
- 판단 기준: D-038 그대로
  - 약관에 자동 접근·수집이나 복제를 명시적으로 금지한 곳만 뺀다
  - '이용자'(비회원 포함) 전체에 걸린 조항만 센다. '회원'에게만 걸린 조항은 회원 가입을 하지 않는 수집 봇에는 적용하지 않는 것으로 본다
  - '상업 이용 금지'만 있는 곳은 "귀띔은 무료·광고 없음"을 근거로 수집했다
- 상태: 기록만. 수집기·결정은 바꾸지 않음. 법률 검토 아님

## 1. 결론

- 광고를 붙이면 **위비티·씽굿·씽유** 세 곳의 수집 근거가 사라짐. 위비티는 1차 수집기(#120)에 들어 있음
- 콘테스트코리아·링커리어·올콘은 이용자 전체에 걸린 제한이 없어 기준상 유지
- 지금(무료·광고 없음)은 6곳 모두 D-038 기준 그대로 수집 가능
- 추천: 광고 충전은 D-039대로 실제 서비스 단계로 미룸. 그때 넣는다면 위비티 이용 허락 요청이 먼저

- 약관 시행일: 위비티 2015-04-06, 콘테스트코리아 2019-05-13, 올콘 2012-04-10, 씽굿 2023-01-01, 링커리어 2026-08-12, 씽유 2018-03-01
- 6곳 모두 '상업적'·'영리'의 정의가 없음. 예시는 "가공, 판매하는 행위 등"뿐이고 광고 수익을 포함하는지는 적혀 있지 않음. 광고 수익은 일반적으로 영리로 보기 쉬워 위 표처럼 판단함
- 6곳 모두 자동 수집을 이용자 전체에 금지한 조항은 없음(링커리어는 회원에게만)
- 출처 표시를 조건으로 허용하는 문구는 약관에 없음. 단 콘테스트코리아 상세 페이지에는 "출처 표기 시 자유롭게 복사 및 배포 가능" 안내가 있음(수집기 작업 중 확인)

### D-038 이후 달라진 점

- 링커리어 약관이 2026-08-12 시행본으로 바뀌어 크롤링·스크래핑을 직접 금지하는 조항(제20조 4항)이 생김. 회원에게만 걸리고 대상이 학습 콘텐츠라 공고 수집에는 해당하지 않는 것으로 봄
- 나머지 5곳은 D-038(2026-11-16) 때 적은 조항과 같음

### 확인 못 한 것

- K-Startup 조회서비스 API(data.go.kr)의 이용 허락 범위(상업 이용 허용 여부)
- 학교 대회 출품작에 광고 수익을 붙여도 되는지(대회 규정)

## 3. 광고 충전을 넣을 경우 바뀌는 범위

| 영역 | 바뀌는 것 |
|---|---|
| 교외 출처 | 위비티 수집 중단 또는 이용 허락(#120 수정). 씽굿·씽유는 확장 후보에서 빠짐. 남는 곳: 콘테스트코리아·링커리어·올콘(+K-Startup 확인 필요). D-038 재결정 |
| 앱 | 광고 SDK(예: AdMob) 추가는 새 라이브러리라 AGENTS.md §2 승인 필요. 크레딧 페이지 "광고 보고 +1" 버튼, 광고 불러오기 실패 처리, 광고 계정 설정 |
| 서버 | 광고 회사가 "광고를 끝까지 봤음"을 서버로 직접 알리는 보상 확인 콜백 경로(서명 검증, 같은 거래 중복 방지, 하루 3회 제한). 앱이 보낸 신호만 믿으면 크레딧을 위조할 수 있음. 크레딧 계산에 '광고 보상' 종류(+1) 추가 |
| 계약 | 크레딧 스키마의 내역 종류, SPEC §5·§7, 샘플. AGENTS.md §3 절차 |
| 처리방침 | "광고, 판매에 쓰지 않습니다" 삭제. 광고 SDK가 가져가는 광고 식별자·기기 정보를 수집 항목에, Google(광고)을 처리 위탁·국외 이전에 추가 |
| 이용약관 | 광고 게재 조항 추가 |
| 결정 기록 | D-038(출처), D-039(충전 규칙) 갱신 |
| 수익 | 광고 1회 수익은 D-039 추정 약 10원(미확인). 리포트 1건 비용 약 1.5~3.3원 |
