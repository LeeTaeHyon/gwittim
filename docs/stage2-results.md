## 0. 한 줄 요약

- LLM(Gemma 12B)에 기대던 분류·추출을 **사람 정답 기반 자체 소형 모델**로 바꾸고, 모두 **통계로 검증**
- 알림톡 종류 정확도 0.42 → **0.83** (Gemma 0.48), 공고 마감 추출 틀린 마감 15건 → **1건** (94건 중)
- 알림톡 수집을 사람 손에서 **폰 수집기 + PC 자동 내보내기**로 자동화

## 1. 평가 잣대부터 세움 (11/13~14, W1~W5)

- 왜: 기존 정답이 Gemma 답을 보고 고친 것 → Gemma에 유리하게 기울 수 있음
- 사람 정답 287건 (D-033)
  - 2명이 원문만 보고 독립 라벨 → 일치도 측정 → 보충 규칙 → 갈린 205칸 합의
  - 일치도: 카테고리 κ 0.60(1차) / 0.565(2차), 전체대상 κ 0.06 → 0.654, 관심사 완전 일치 52% → 80%
  - 발표 때 주의: 2차는 AI 제안이 섞여 독립 일치도보다 높게 나옴 → 두 값 함께 제시
- 통계 도구 (PR #85): Wilson 구간, McNemar, 부트스트랩, Cohen κ
- 교차 검증 (PR #89): 5겹 × 씨앗 5개, 재공지는 같은 겹으로 묶어 정보 누출 차단
- 서버(Python) ↔ 앱(Dart) 동일 계산 검증 (PR #87): 합성 점검 문장 51개, 287건 확률 차 1e-7 수준
- 게시판 정답표 표본 100건 채점 도구 (PR #88)

## 2. 알림톡 분류 모델 교체 (11/15, D-035·D-037)

- 문제: Gemma 라벨로 학습한 자체 모델이 사람 기준으로 Gemma보다 낮음 (0.418 vs 0.498)
  - 원인: Gemma의 버릇을 그대로 배움, Gemma 라벨에 '기타'가 없어 모델도 못 냄
- 해결 1: 사람 정답으로 학습 (D-035)

  | 종류 정확도 (교차 검증, 사람 정답) | 값 |
  |---|---|
  | 규칙 | 0.467 |
  | Gemma 12B | 0.498 |
  | 자체, Gemma 라벨 학습 (이전 앱) | 0.418 |
  | **자체, 사람 정답 학습** | **0.782** |

  - 짝 비교 McNemar p < 0.0001, 95% 구간 0.725~0.821
  - 재공지 암기 아님 확인: 학습에 같은 제목 있는 공지 0.779 / 없는 공지 0.783
- 해결 2: 오류 사례 분석 → 보강 (D-037)
  - 씨앗 5개 중 4번 이상 틀린 52건 분석 → 사람 정답 불일치 6건 발견·정정
  - 드문 종류 가중치 학습 → **0.831** (Gemma 0.477, 규칙 0.446). 해외연수 17 → 30/30
- 관심사: 정확히 일치 0.759 → **0.841** (씨앗 5개 중 4개 p < 0.05)
- 부수 효과: Gemma로 넘기던 공지 61 → 0건 (GPU 호출 거의 없어짐)
- 폰 안 계산: S25 Ultra 1건 분류 p95 **0.084ms**, 서버와 287/287 동일 (D-034)

## 3. 알림톡 수집 자동화 (11/15~18, D-034·D-036·D-040·D-041)

- 전: PC 카톡을 사람이 손으로 내보냄 → 10/29 이후 공고 6건 놓침
- 후
  - 팀장 폰 1대가 학교 채널 알림만 읽음 → 개인 알림 거르기·개인정보 가림·분류를 **폰 안에서** → 서버 받은편지함 → 정기 배치 (D-034·D-036)
  - 일반 사용자에게 알림 권한 요구 없음 (공통 알림톡은 누구 폰이든 같음)
  - 폰 거르기·가림 결과 PC 파서와 665/665 일치, 서버 수신 439/439
- 발견: 카톡 알림 본문이 200자로 잘림 → 마감 근거 36%, 활동 기간 35%가 잘린 뒤쪽에 있음 (D-041)
  - 대응 1: 폰으로만 받은 공고에 "미리보기" 안내 표시 (D-040)
  - 대응 2: 정기 배치 직전 PC 카톡 6개 방 **자동 내보내기**로 전문 채움, 17초 (D-041)
  - 안전장치: PC 사용 중·화면 잠김이면 건너뜀, 입력칸에는 아무것도 안 보냄
- 실제 결과: 놓쳤던 새 공고 6건 수집, 폰 미리보기 공고 2건이 200자 → 449·306자 전문으로 갱신

## 4. 공고 분석(마감·조건 추출) 자체 모델 (11/18, D-042, PR #104)

- 문제: Gemma가 마감 추출에서 놓친 7건을 메우는 대신 **없는 마감 7건을 지어냄**, 공고당 4.5초·GPU 필요
- 방법: "날짜를 쓰는 모델"이 아니라 **"마감·조건이 적힌 줄을 고르는 모델"** (KoELECTRA-base, 줄 분류)
  - 근거가 항상 원문 한 줄 → 지어낸 문구가 나올 수 없음
  - 라벨 801건: 상위 LLM 초벌(DeepSeek) + Claude 검수 (지식 증류)
  - 학습: 팀원 RTX 5070, 약 2분
- 결과 (시험 공고 94건, 참고 라벨 기준)

  | | 규칙 | 규칙+Gemma (이전) | 이번 분석기 |
  |---|---|---|---|
  | 마감 맞음 | 80 | 77 | **84** |
  | 틀린 마감 + 없는데 만든 마감 | 6 | 15 | **1** |
  | 기타 조건 찾은 비율 | 50% | 68% | **82%** |
  | 속도 | — | 4.5초/건 (GPU) | **0.1초/건 (CPU)** |

- 오류 분석에서 배운 것
  - 틀린 마감 대부분은 모델이 아니라 **날짜 파서**가 범위 끝을 못 읽은 것 → 파서 보강으로 틀린 마감 검증 4 → 0, 시험 2 → 0
  - 문턱은 검증 세트로만 고름 (시험 세트로 고르면 과적합 → 시험 점수가 더 오르는 값도 채택 안 함)
  - 시도했다가 버린 것: 기타 조건 규칙 필터 (검증에서 나빠짐)

## 4.5 맞춤 에이전트·교외 공고·홈 개편 (11/19~22, D-038·D-039)

- 맞춤 에이전트(AI 상세 분석): 공고 하나를 내 기준으로 4칸(맞는 점·지원 자격·할 일·필요 역량) 정리. 서버·앱 모두 main 병합(#105~#119)
  - 개인정보: 보낼 값 허용 목록(이름·이메일·계정 ID는 보낼 길이 없음), 요청 때만 묻는 칩 3종(자유 입력 없음), 첫 사용 때 한 번 동의, 리포트는 마감 + 30일 보관
  - 크레딧: 가입 5·매일 1·최대 5, AI 호출 전 잡아 두고 성공 시 확정·실패 시 환불(두 단계 차감)
  - 지시문: 이미 계산된 지원 조건 판정과 다르게 말하지 않음, 합격 가능성 말하지 않음, 공고에 적힌 역량만
  - 실제 공고 1건 + 로컬 Claude(Haiku 5.5)로 확인: 4칸 정상, 판정과 같게 서술, 지어낸 역량 없음
- 교외 공모전 자동 수집 1차: 위비티·콘테스트코리아(PR #120). robots·3초 간격·실행당 상한을 코드로 강제, 출처당 상세 3건 시험 수집 3/3 파싱 성공
- 홈 개편: 오늘의 귀띔 강조(하루 첫 접속 도착 장면), 공고 카드 분류 아이콘·상태 원(#119). 지인 피드백 "텍스트만 있어 딱딱함" 반영
- 밤 자동 작업: 큐 문서 + 하나씩 처리·검증·PR로 PR 리뷰·조사·계약 초안을 사람 없이 진행(11/19·11/21 밤)

## 5. 방법론 (발표용 메시지)

- 정답을 먼저 세우고 → 모델을 고름 (Gemma 기준 정답 → 사람 정답)
- 모든 비교는 같은 공지·같은 씨앗끼리 짝 비교 + 유의성 검정
- 오류를 사례별로 뜯어 원인을 나눔: 정답 불일치 / 파서 / 문턱 / 모델 → 원인별로 다르게 고침
- 큰 LLM은 "선생"(라벨 초벌·애매한 경우)으로, 운영은 작고 빠른 자체 모델로
- 개인정보: 폰 안에서 거르고 가린 뒤에만 서버로

## 7. 한계·진행 중

- 알림톡 모델: 287건 안의 교차 검증. 학습 뒤 새로 온 알림톡으로 따로 재지 않음
- 장학(2건)·드문 관심사는 예시가 적어 거의 못 맞힘
- 공고 분석 모델: 정답이 사람이 아닌 상위 LLM 라벨. 학년·휴학·졸업 조건은 시험 예시 0~4건이라 판단 불가
- 기타 조건 라벨 기준 확정(지원 비율·선발 순서·대상 넓히는 말도 "직접 확인 조건") → 재검수·재학습 예정
- 다음 후보: 드문 조건 라벨 보강, 시드 앙상블, 5겹 교차 검증으로 결정
- 맞춤 에이전트: 실제 AI는 로컬 구독 CLI로만 확인. Anthropic API 전환(P9)·월 비용 상한은 #121, 실제 API 호출은 키 발급 후
- 교외 공고: 1차 2곳만(#120 병합 전). 두 사이트 중복 공고, 주최 측 페이지 따라가기, 링커리어·씽굿은 다음
- 광고 충전: 넣으면 위비티·씽굿·씽유 수집 근거가 사라져 실제 서비스 단계로 미룸(source-terms-review-ads.md)
- 화면 잠금 상태 자동 내보내기, 실제 정기 배치에서 자체 모델 동작: 확인 전
- 대부분 결정이 "팀원 확인 전" 상태
