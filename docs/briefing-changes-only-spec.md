## 1. 목표와 범위

브리핑은 "어제와 달라진 것"만 전합니다. 홈 말풍선의 건수, 브리핑 머리의 숫자, 브리핑 본문이 같은 목록을 가리키게 합니다.

**범위**
- 브리핑에 넣을 소식을 고르는 계산(`briefing_data.dart`)
- 브리핑 화면의 소식 카드와 머리 숫자(`briefing_screen.dart`, `briefing_stats.dart`)
- 홈 말풍선이 건수를 읽는 곳, 관련 테스트
- `docs/ui-style.md`, `docs/decisions.md`(D-051 추가)

**범위 밖**
- 서버·계약·사전, 추천 순서는 바꾸지 않습니다.
- 도착 장면의 모양과 시간, 브리핑 머리의 모양, 하루 첫 접속 때 자동으로 여는 규칙은 그대로입니다.
- 홈의 줄 구성은 홈 한 목록 명세 그대로입니다.
- 새 패키지, 새 색 토큰, 새 글자 크기를 더하지 않습니다.

## 2. 배경: 왜 바꾸는가

2026-11-23 에뮬레이터 화면(컴퓨터공학과 프로필)과 실제 공고 610건으로 본 것입니다. 지난 날 계산은 근사이고, 저장한 공고는 없다고 보았습니다.

- 브리핑 머리는 '마감 임박 8 · 새 공고 2'인데 본문에 나오는 마감 임박 공고는 1건입니다.
- 브리핑에 이름이 나오는 공고는 프로필 3종 × 14일 모든 날에 새 홈의 줄에 이미 있습니다.
- 마감 임박은 가장 가까운 1건을 고르는 규칙이라, 그 공고의 마감이 지날 때까지 같은 카드가 맨 위에 옵니다.
- 14일 동안 '졸업생 진로 추천' 카드는 0번, '진로 관련 기회'는 1번 나왔습니다.
- 푸시 알림이 P0 제외라 앱을 열 때 받는 알림은 브리핑뿐입니다. 알림이라면 같은 공고의 D-4, D-3을 매일 다시 보내지 않습니다.

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 브리핑이 뜨는 날(컴공 / 전자 / 숭의, 14일) | 13 / 14 / 1 | 13 / 11 / 0 |
| '확인할 공고 N건' 중앙값(컴공) | 6 | 2 |

## 3. 소식의 종류

| 순서 | 소식 | 지금 | 바꾼 뒤 |
|---|---|---|---|
| 1 | 오늘 마감 | 없음 | **새로 둠**(§3.1) |
| 2 | 저장한 공고 마감 변경 | 있음(맨 아래) | 그대로, 둘째로 올림 |
| 3 | 새 공고 | 있음 | 그대로 |
| 4 | 졸업생 진로 추천 | 있음 | 그대로, 맨 아래로 내림 |
| | 저장한 공고 곧 마감(이틀 안) | 있음 | **뺌**(오늘 마감분만 1에 들어감) |
| | 마감 임박(7일 안 가장 가까운 1건) | 있음 | **뺌** |
| | 진로 관련 기회 | 있음 | **뺌** |

### 3.1 오늘 마감

- 저장한 모집 중 공고 중 `daysLeft == 0`인 것
- 맞춤 추천(`list.personalized`)이면 `deadlineCandidates(list)` 중 `daysLeft == 0`인 것도 넣습니다. 최신 모드에서는 저장한 공고만 넣습니다.
- 같은 공고는 한 번만 넣습니다. 추천 목록과 저장 목록 둘 다에 있으면 두 정보를 모두 담습니다.
- 순서: 저장한 공고 먼저 → 추천 순서
- 홈 한 목록에서 만든 줄 값(공고 요약, 추천 정보, 저장 정보)을 그대로 씁니다.

### 3.2 그대로 두는 규칙

- 새 공고: 최근 3일 안에 게시된 관련 공고(맞춤 추천일 때만)
- 저장한 공고 마감 변경: 저장한 뒤 마감이 바뀐 모집 중 공고
- 졸업생 진로 추천: 답하지 않은 것 중 7일 안 마감이 가장 가까운 1건. 지금은 '저장 곧 마감'에 나온 공고를 빼는데, 이제는 '오늘 마감'에 나온 공고를 뺍니다.

### 3.3 `Briefing`에서 바뀌는 것

- 더함: 오늘 마감 목록
- 뺌: `savedSoon`, `urgent`, `urgentIds`, `career`. 쓰는 곳이 없어지면 `onlyChanged`, `briefingStatTitle`, `buildBriefing`의 `hasInterests` 인자, 상수 `savedSoonDays`도 지웁니다. `urgentDays`는 홈과 달력에서 쓰므로 남깁니다.
- `isEmpty`: 오늘 마감, 마감 변경, 새 공고, 졸업생 진로 추천이 모두 없을 때
- `distinctNoticeCount`: 위 네 가지의 공고 ID 합집합 수(도착 장면의 '확인할 공고 N건')
- 숫자 줄의 종류(`BriefingStatKind`)는 오늘 마감 → 마감 변경 → 새 공고 순서의 셋입니다. 졸업생 진로 추천은 지금처럼 숫자 줄에 넣지 않습니다.

### 3.4 홈 말풍선과 한 곳에서 읽기

- 홈 말풍선의 세 건수(오늘 마감, 마감 변경, 새 공고)는 `Briefing`의 세 목록 길이를 그대로 씁니다. 홈 쪽에 같은 계산이 따로 있으면 지웁니다.
- 말풍선이 보이면 브리핑은 비어 있지 않습니다. 테스트로 확인합니다.

## 4. 화면 규칙

머리, 소식 카드(§3 순서), 아래 안내 문장, '확인' 버튼 순서는 지금과 같습니다.

### 4.1 머리의 숫자 줄

| 종류 | 아이콘 | 이름 | 숫자 색 |
|---|---|---|---|
| 오늘 마감 | `alarm_rounded` | '오늘 마감' | `heroUrgent`(아이콘도) |
| 마감 변경 | `update_rounded` | '마감 변경' | `loginInk` |
| 새 공고 | `fiber_new_rounded` | '새 공고' | `loginInk` |

크기와 배치는 지금의 `BriefingStatRow` 그대로이고, 0건은 보이지 않습니다. 제목 '오늘의 주요 소식'은 바꾸지 않습니다.

### 4.2 오늘 마감 카드(새로 만듦)

지금의 `_ListBubble`과 같은 모양의 말풍선 카드입니다.

- 위 작은 글자: '오늘 마감'(`urgent`)
- 제목: '오늘 신청이 마감되는\n공고 ' 뒤에 'N건'(형광펜, `_ListBubble`과 같은 방식)
- 줄(3건까지): 왼쪽 칩 + 제목 한 줄. 누르면 그 공고의 리포트가 열립니다.
  - 칩은 `_ListBubble`의 칩과 같은 모양입니다. 마감 시각이 있으면 '17:00', 없으면 '오늘'
  - 저장한 공고는 제목 오른쪽에 책갈피 아이콘(`GwIcon`의 저장함 모양, 16, `muted`)을 두고, 화면 읽기 이름은 '저장한 공고'입니다.
- 3건을 넘으면 아래에 '외 N건은 달력 탭에서 볼 수 있습니다'(캡션)

### 4.3 그대로 두는 카드

- 저장한 공고 마감 변경(`_ChangedBubble`), 새 공고(`_ListBubble`), 졸업생 진로 추천(`_MajorPickBubble`)은 모양과 문구를 바꾸지 않습니다.
- 다만 `_ListBubble` 칩의 '마감 미상'은 다른 화면과 같게 '마감일 없음'으로 바꿉니다(가이드 §7의 표기).

### 4.4 지우는 것

- `_UrgentBubble`(7일 날짜 띠가 있는 카드), `_SavedSoonBubble`, '진로 관련 기회' 목록
- `briefing_stats.dart`의 종류 가운데 마감 임박, 저장 곧 마감, 진로 관련

### 4.5 지키는 것

- 아래 안내 문장 '추천 순서는 … 합격 가능성과는 관계없습니다.'는 그대로 둡니다(D-009).
- 문장은 템플릿입니다. 마감 시각·날짜를 추정하지 않고, 마감일 없는 공고는 '오늘 마감'에 넣지 않습니다.
- 문구는 가이드 §2(명사형·합쇼체, 해요체 없음)를 따릅니다.

## 5. 테스트

없어지는 소식을 보는 테스트(저장 곧 마감 이틀, 마감 임박 1건, 진로 관련, 숫자 칸 다섯 종류)는 새 규칙으로 고치거나 지웁니다. 지운 테스트는 보고에 적습니다.

**계산**
- 오늘 마감: 저장한 공고와 관련 공고 중 오늘 마감만, 같은 공고는 한 번, 저장한 공고 먼저. 내일 마감·마감일 없음·모집 중 아님은 들어가지 않는다.
- 최신 모드에서는 오늘 마감에 저장한 공고만 들어간다.
- 7일 안 마감이 있어도 오늘 마감·마감 변경·새 공고·졸업생 진로 추천이 없으면 브리핑은 비어 있다.
- 졸업생 진로 추천은 오늘 마감에 나온 공고를 고르지 않는다.
- `distinctNoticeCount`는 네 가지의 합집합 수다.
- 숫자 줄은 오늘 마감 → 마감 변경 → 새 공고 순서이고 0건은 없다.

**화면**
- 머리 숫자 줄의 이름·개수·화면 읽기 이름
- 오늘 마감 카드: 제목의 건수, 칩(시각 또는 '오늘'), 저장한 공고 표시, 3건 넘을 때의 안내, 줄을 누르면 리포트
- 카드 순서가 §3과 같다.
- 홈 말풍선의 건수와 브리핑 머리의 숫자가 같다.
- 도착 장면의 '확인할 공고 N건'이 새 수와 같다. 브리핑이 비면 자동으로 열리지 않는다.
- `text_scale_test.dart`, `theme_test.dart`가 그대로 통과한다.

## 8. 알려진 한계(구현하면서 고치지 않음)

- 7일 날짜 띠가 있는 마감 임박 카드가 없어져 브리핑이 지금보다 단순해집니다.
- 달라진 것이 적은 날은 카드가 하나뿐일 수 있습니다.
- 저장한 공고의 내일·모레 마감은 브리핑에 나오지 않습니다. 홈 '이번 주 마감' 줄에는 '저장한 공고' 표시와 함께 나옵니다.
- 졸업생 진로 추천만 있는 날은 브리핑이 자동으로 뜨지만 홈 말풍선은 없어, 닫은 뒤 홈에서 다시 열 수 없습니다. 답하지 않았으면 다음 날 첫 접속 때 다시 뜹니다.
- 새 공고는 최근 3일 기준이라 같은 공고가 최대 3일 동안 나옵니다.
- 브리핑의 공고는 여전히 홈에도 있습니다. 브리핑 화면을 없애고 도착 장면만 남길지는 사용자 테스트 뒤에 정합니다.
